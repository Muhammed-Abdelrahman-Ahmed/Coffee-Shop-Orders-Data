# Coffee-Shop-Orders-Data
An interactive Dashboard for coffee sales from 2019 to 2022 using Excel, Power Query, and Power Pivot with UI/UX principles.

### 📅 Project Timeline
* **Development Period:** October 2026 .
* **Note:** This project was developed locally and later migrated to GitHub .

This project is an end-to-end data analysis of coffee sales, built entirely within Microsoft Excel. The goal was to take raw sales data and turn it into an interactive dashboard to track key metrics and uncover business insights.

## Tools I Used
- Microsoft Excel
- Power Query
- Power Pivot

## Project Workflow
Here is a breakdown of the steps I took to build this project:

1. Data Cleaning and Preparation
I started by importing the raw dataset into Power Query. I cleaned the data, formatted the columns, and ensured everything was structured properly before moving on to the analysis phase.

2. Asking the Right Questions
Before crunching the numbers, I outlined the main business questions I wanted this dashboard to answer. For example, identifying the best-selling coffee types, understanding profit margins across different regions, and tracking sales trends over time.

3. Data Exploration
With a clear direction in mind, I used Pivot Tables to explore the cleaned dataset and start finding the answers to my initial questions.

4. Data Modeling and Measures
To handle more complex calculations and connect different tables, I used Power Pivot. I built a relational data model and wrote custom measures to calculate key performance indicators (KPIs) like Total Sales, Total Profit, and Average Order Value.

5. Designing the Dashboard
In the final step, I built an interactive dashboard using Pivot Tables. I added slicers for things like date, roast type, size, and customer loyalty, so users can easily filter the data and see how the metrics change dynamically.
